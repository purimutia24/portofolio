Featured Backend Project

SIMPONI – Sistem Informasi Pelaporan

Peran: Backend Developer

Aplikasi pelaporan dan pelacakan berbasis web yang mengimplementasikan sistem keamanan pembatasan hak akses secara spesifik untuk penggunanya guna mencegah kebocoran data antar departemen.

Problem

Proses pelaporan sebelumnya tidak memiliki pembatasan hak akses yang jelas sehingga rentan terhadap kebocoran data sensitif antar departemen.

Solution

Membangun sistem terpusat dengan autentikasi Role-Based Access Control (RBAC) agar dokumen hanya bisa diakses dan digenerate oleh peran yang berwenang.

Kontribusi Saya & Alur Pengerjaan

Merancang struktur tabel dan relasi pada basis data MySQL, menulis endpoint REST API menggunakan framework modern FastAPI, mengonfigurasi dependensi keamanan RBAC, dan melakukan pengujian respons API sebelum diintegrasikan dengan frontend React.

Hasil Implementasi

Sistem backend berhasil terintegrasi dengan frontend React, mampu melayani request secara aman, dan menghasilkan dokumen otomatis sesuai peran pengguna.

Python FastAPI MySQL RBAC Auth React (Integrasi)

CRUD MongoDB (Arsitektur MVC)

Peran: Backend Developer

Aplikasi backend untuk mengelola operasi dasar basis data pada lingkungan NoSQL menggunakan pendekatan arsitektur Model-View-Controller (MVC) agar basis kode rapi dan modular.

Problem

Membutuhkan pengelolaan data yang fleksibel tanpa skema tabel SQL kaku, namun struktur kode backend harus tetap rapi dan mudah di-maintain.

Solution

Mengembangkan server aplikasi menggunakan Node.js dan MongoDB, serta memisahkan logika aplikasi ke dalam direktori Controller, Model, dan Routes.

Kontribusi Saya & Alur Pengerjaan

Melakukan inisiasi project Node.js, menyusun arsitektur direktori kerja (MVC) pada sisi server, membuat routing data, dan mengatur koneksi ke database NoSQL MongoDB.

Hasil Implementasi

Terciptanya server backend Node.js yang ringan dan efisien untuk mengelola manipulasi data dokumen pada MongoDB secara langsung.
